================================================================================
一、项目概述
================================================================================

项目名称：柴油机润滑系统教学辅助系统
项目类型：B/S架构 Web 应用（前后端分离）
项目目的：制作柴油机润滑系统的结构展示、操作演示等方面教学辅助系统，
          供自学者进行学习，支持交互式自主选择学习内容和在线知识测试。

系统功能模块：
  1. 用户登录模块 —— 固定账号密码登录（LH666/123456）
  2. 基本介绍模块 —— 系统概述、结构图、教学视频
  3. 学习目录模块 —— 四大知识板块入口
  4. 知识详情模块 —— 各板块的概念、结构展示、实物图片
  5. 在线测试模块 —— 15道选择题、自动评分、答题解析
  6. 学习统计模块 —— 数据图表、学习进度追踪


================================================================================
二、技术栈说明
================================================================================

【后端技术】
  - Node.js        —— JavaScript 运行时环境
  - Express 4.18   —— Web 应用框架，处理HTTP请求和路由
  - sql.js 1.10    —— 纯JavaScript实现的SQLite数据库引擎
  - jsonwebtoken    —— JWT令牌生成和验证，用于用户认证

【前端技术】
  - Vue 3.5        —— 渐进式 JavaScript 框架（使用Composition API）
  - Vue Router 4   —— 官方路由管理器，实现页面导航
  - Vite 8         —— 现代前端构建工具，提供开发服务器和热更新
  - Axios          —— HTTP 请求库，与后端API通信

【数据库】
  - SQLite         —— 轻量级嵌入式关系数据库，数据存储在单个文件中

================================================================================
四、后端代码说明
================================================================================

----- 4.1 server.js（后端主程序）-----

这是后端的核心文件，主要包含以下部分：

  1. 依赖引入和配置
     - 引入 express、cors、jsonwebtoken 等模块
     - 设置端口号 3000
     - 设置 JWT 密钥

  2. 中间件配置
     - cors()：允许前端跨域访问
     - express.json()：解析JSON请求体
     - authMiddleware：JWT认证中间件，验证用户登录状态

  3. API 路由（共12个接口）
     - POST /api/login              用户登录
     - GET  /api/user/info          获取用户信息
     - GET  /api/introduction       获取基本介绍
     - GET  /api/sections           获取所有板块
     - GET  /api/sections/:id       获取板块详情
     - GET  /api/quizzes            获取测试题
     - POST /api/quiz/submit        提交答卷
     - GET  /api/quiz/history       获取答题历史
     - GET  /api/stats              获取基础统计
     - GET  /api/stats/detail       获取详细统计（驱动图表）
     - POST /api/learn/record       记录学习行为
     - GET  /api/learn/progress     获取学习进度

  4. 数据处理逻辑
     - sql.js 返回的数据格式为 {columns:[], values:[[]]}
     - 每个接口都将其转换为标准的 JSON 对象数组
     - 写入操作后调用 saveDB() 持久化到磁盘


----- 4.2 database.js（数据库模块）-----

  1. getDB()  —— 获取数据库实例（单例模式）
     - 首次调用时初始化数据库
     - 如果 data.db 文件存在，从文件加载
     - 如果不存在，创建新数据库并填充示例数据

  2. saveDB() —— 将内存中的数据库导出并写入磁盘文件

  3. initTables() —— 创建所有数据表

  4. seedData() —— 填充示例数据
     - 2个用户（学员 + 管理员）
     - 1条基本介绍
     - 4个学习板块
     - 5条内容记录（每个板块1-2条）
     - 22条子项记录（知识点详情）
     - 15道测试题（含正确答案和解析）


================================================================================
五、前端代码说明
================================================================================

----- 5.1 main.js（入口文件）-----

  创建 Vue 应用实例，注册路由插件，引入全局样式，挂载到 #app。


----- 5.2 router/index.js（路由配置）-----

  定义了 7 个页面路由：
  
  路径              组件              说明              需要登录
  /                 -                 重定向到/login    否
  /login            Login.vue         登录页            否
  /home             Home.vue          首页              是
  /intro            Introduction.vue  基本介绍          是
  /catalog          Catalog.vue       学习目录          是
  /section/:id      Section.vue       板块详情          是
  /quiz             Quiz.vue          知识测试          是
  /result           Result.vue        测试结果          是

  路由守卫：在 beforeEach 中检查 localStorage 里的 token，
  未登录用户访问需认证页面时自动跳转到登录页。


----- 5.3 utils/api.js（请求封装）-----

  基于 Axios 创建请求实例：
  - baseURL 设为 /api（通过 Vite 代理转发到后端）
  - 请求拦截器：自动从 localStorage 读取 token 并添加到请求头
  - 响应拦截器：401 状态自动清除 token 并跳转登录页


----- 5.4 views/Login.vue（登录页）-----

  功能：
  - 表单输入账号和密码
  - 调用 POST /api/login 接口验证
  - 登录成功后将 token 和用户信息存入 localStorage
  - 跳转到首页
  
  交互：
  - 输入框聚焦高亮
  - 回车键触发登录
  - 错误提示（账号密码为空、密码错误、网络错误）
  - 登录按钮加载状态


----- 5.5 views/Home.vue（首页）-----

  功能：
  - 显示用户昵称和退出登录按钮
  - 从 /api/stats/detail 获取详细统计数据
  - 从 /api/learn/progress 获取学习进度数据
  - 三个数据图表（纯CSS/SVG实现）：
    * 环形图：答题正确率（SVG stroke-dasharray 动态计算）
    * 进度条图：4个板块的学习次数
    * 完成度图：已答题目数、已学板块数、总答题次数
  - 三个功能入口卡片（基本介绍、学习目录、知识测试）

  数据驱动：所有图表数据均从后端API实时获取，
  用户每次答题或访问板块后，刷新首页即可看到数据变化。


----- 5.6 views/Introduction.vue（基本介绍页）-----

  功能：
  - 从 /api/introduction 获取介绍内容
  - 显示系统概述文字
  - 展示2张润滑系统结构示意图（本地素材）
  - 嵌入教学视频播放器（本地素材 video.mp4）
  - 显示5个核心要点


----- 5.7 views/Catalog.vue（学习目录页）-----

  功能：
  - 从 /api/sections 获取4个板块数据
  - 以2x2网格展示板块卡片
  - 每张卡片显示序号、标题、描述、封面图
  - 点击卡片跳转到对应板块详情页


----- 5.8 views/Section.vue（板块详情页）-----

  功能：
  - 根据路由参数 id 从 /api/sections/:id 获取板块数据
  - 进入页面时自动调用 POST /api/learn/record 记录学习行为
  - Tab 切换不同内容类别（如"主要作用"和"润滑方式"）
  - 手风琴式展开/收起知识点
  - 每个知识点包含标题、详细描述、对应素材图片
  - 底部导航按钮：上一板块 / 下一板块 / 开始测试

  数据来源：
  - 文字内容：从后端API获取
  - 图片：使用本地素材文件（/materials/img/）


----- 5.9 views/Quiz.vue（知识测试页）-----

  功能：
  - 从 /api/quizzes 获取15道选择题
  - 逐题显示，支持上一题/下一题切换
  - 进度条显示当前答题进度
  - 底部圆点导航，可任意跳转到某题
  - 已答题目圆点变色提示
  - 全部答完后提交到 POST /api/quiz/submit
  - 后端计算成绩后返回评分和每题解析
  - 结果存入 sessionStorage 后跳转到结果页

  数据流：
  用户答案 -> POST到后端 -> 后端与正确答案对比 ->
  结果写入quiz_records表 -> 返回评分和解析 -> 前端展示


----- 5.10 views/Result.vue（测试结果页）-----

  功能：
  - 从 sessionStorage 读取答题结果
  - 环形分数展示（90+绿色/60+橙色/60以下红色）
  - 显示总题数、答对数、评语
  - 逐题详情列表：题目、用户答案、正确答案、解析
  - 正确题目绿色左边框，错误题目红色左边框
  - 重新测试和继续学习按钮


----- 5.11 assets/css/global.css（全局样式）-----

  定义CSS变量（设计体系）：
  - 主色调：深绿色系（#2d6a4f / #40916c / #52b788）
  - 清新自然的配色方案，非蓝紫渐变
  - 文字颜色、背景色、边框色、阴影
  - 圆角尺寸（sm/md/lg/xl）
  - 页面过渡动画（fade/slide）


================================================================================
六、数据库设计说明
================================================================================

数据库类型：SQLite（文件：backend/data.db）
共 7 张数据表：

----- 表1：users（用户表）-----
  字段          类型        说明
  id            INTEGER     主键，自增
  username      TEXT        用户名（唯一）
  password      TEXT        密码
  nickname      TEXT        昵称
  role          TEXT        角色（student/admin）
  created_at    DATETIME    创建时间

  示例数据：LH666/123456（学员）、admin/admin123（管理员）


----- 表2：sections（板块表）-----
  字段          类型        说明
  id            INTEGER     主键，自增
  title         TEXT        板块标题
  subtitle      TEXT        副标题
  description   TEXT        描述
  cover_image   TEXT        封面图URL
  sort_order    INTEGER     排序序号

  数据：4条（主要作用和润滑方式、组成、油路、润滑剂）


----- 表3：contents（内容表）-----
  字段          类型        说明
  id            INTEGER     主键，自增
  section_id    INTEGER     所属板块ID（外键）
  title         TEXT        内容标题
  content_type  TEXT        内容类型（concept）
  content_text  TEXT        内容文字
  image_url     TEXT        图片URL
  sort_order    INTEGER     排序序号

  数据：5条（每个板块1-2条内容分类）


----- 表4：sub_items（子项表）-----
  字段          类型        说明
  id            INTEGER     主键，自增
  content_id    INTEGER     所属内容ID（外键）
  title         TEXT        子项标题
  description   TEXT        详细描述
  image_url     TEXT        图片URL
  sort_order    INTEGER     排序序号

  数据：22条（所有知识点的详细内容）


----- 表5：quizzes（测试题表）-----
  字段           类型        说明
  id             INTEGER     主键，自增
  question       TEXT        题目
  option_a       TEXT        选项A
  option_b       TEXT        选项B
  option_c       TEXT        选项C
  option_d       TEXT        选项D
  correct_answer TEXT        正确答案（A/B/C/D）
  explanation    TEXT        答案解析
  sort_order     INTEGER     排序序号

  数据：15条


----- 表6：quiz_records（答题记录表）-----
  字段          类型        说明
  id            INTEGER     主键，自增
  user_id       INTEGER     用户ID（外键）
  quiz_id       INTEGER     题目ID（外键）
  user_answer   TEXT        用户答案
  is_correct    INTEGER     是否正确（0/1）
  created_at    DATETIME    答题时间

  数据：用户答题时实时写入


----- 表7：learn_records（学习记录表）-----
  字段          类型        说明
  id            INTEGER     主键，自增
  user_id       INTEGER     用户ID（外键）
  section_id    INTEGER     板块ID（外键）
  created_at    DATETIME    访问时间

  数据：用户访问板块时实时写入


----- 表8：introduction（介绍表）-----
  字段          类型        说明
  id            INTEGER     主键，自增
  title         TEXT        标题
  content       TEXT        介绍内容
  video_url     TEXT        视频URL
  image_url     TEXT        图片URL

  数据：1条

七、API接口文档
================================================================================

基础地址：http://localhost:3000/api
认证方式：Bearer Token（在请求头 Authorization 中携带）

----- 1. 用户登录 -----
  请求：POST /api/login
  参数：{"username": "LH666", "password": "123456"}
  响应：{
    "code": 200,
    "message": "登录成功",
    "data": {
      "token": "eyJhbGci...",
      "user": {"id":1, "username":"LH666", "nickname":"学员", "role":"student"}
    }
  }

----- 2. 获取用户信息 -----
  请求：GET /api/user/info（需认证）
  响应：{"code":200, "data":{"id":1, "username":"LH666", ...}}

----- 3. 获取基本介绍 -----
  请求：GET /api/introduction
  响应：{"code":200, "data":{"id":1, "title":"...", "content":"...", ...}}

----- 4. 获取板块列表 -----
  请求：GET /api/sections
  响应：{"code":200, "data":[{"id":1, "title":"主要作用和润滑方式", ...}, ...]}

----- 5. 获取板块详情 -----
  请求：GET /api/sections/1
  响应：{"code":200, "data":{
    "id":1, "title":"...",
    "contents":[{
      "id":1, "title":"主要作用",
      "sub_items":[{"id":1, "title":"润滑作用", "description":"..."}, ...]
    }, ...]
  }}

----- 6. 获取测试题 -----
  请求：GET /api/quizzes
  响应：{"code":200, "data":[{"id":1, "question":"...", "option_a":"...", ...}, ...]}

----- 7. 提交答卷 -----
  请求：POST /api/quiz/submit（需认证）
  参数：{"answers":[{"quiz_id":1, "user_answer":"C"}, ...]}
  响应：{"code":200, "data":{
    "total":15, "correct":12, "score":80,
    "results":[{"quiz_id":1, "is_correct":true, "explanation":"..."}, ...]
  }}
  说明：答题结果实时写入数据库 quiz_records 表

----- 8. 获取答题历史 -----
  请求：GET /api/quiz/history（需认证）
  响应：{"code":200, "data":[{"quiz_id":1, "user_answer":"C", ...}, ...]}

----- 9. 获取基础统计 -----
  请求：GET /api/stats（需认证）
  响应：{"code":200, "data":{
    "totalQuizzes":15, "answeredQuizzes":10, "correctRate":80, "totalSections":4
  }}

----- 10. 获取详细统计 -----
  请求：GET /api/stats/detail（需认证）
  响应：{"code":200, "data":{
    "totalQuizzes":15, "totalRecords":15, "correctRecords":12,
    "wrongRecords":3, "answeredQuizzes":15, "learnedSections":3,
    "totalSections":4, "correctRate":80,
    "quizStats":[{"id":1, "question":"...", "correct_count":1, "total_count":1}, ...]
  }}
  说明：该接口为首页图表提供数据，所有数值随用户操作实时变化

----- 11. 记录学习行为 -----
  请求：POST /api/learn/record（需认证）
  参数：{"section_id": 1}
  响应：{"code":200, "message":"记录成功"}
  说明：每次进入板块详情页自动调用，写入 learn_records 表

----- 12. 获取学习进度 -----
  请求：GET /api/learn/progress（需认证）
  响应：{"code":200, "data":[
    {"id":1, "title":"主要作用和润滑方式", "visit_count":5}, ...
  ]}


================================================================================
八、前后端数据流说明
================================================================================

【登录流程】
  前端输入账号密码 -> POST /api/login -> 后端查询users表验证
  -> 验证通过生成JWT Token -> 前端保存Token到localStorage
  -> 后续请求自动携带Token

【学习流程】
  首页 -> 点击"学习目录" -> GET /api/sections获取板块列表
  -> 点击某板块 -> GET /api/sections/:id 获取详情
  -> 同时 POST /api/learn/record 记录学习行为写入数据库
  -> 展开知识点查看详情和图片

【测试流程】
  点击"知识测试" -> GET /api/quizzes 获取15道题
  -> 逐题作答 -> 全部答完点击提交
  -> POST /api/quiz/submit 提交答案
  -> 后端逐题对比正确答案，计算分数
  -> 答题记录写入quiz_records表（持久化到磁盘）
  -> 返回评分结果 -> 前端展示成绩和解析

【统计图表数据流】
  首页加载 -> GET /api/stats/detail 获取统计数据
  -> 包含：正确/错误题数、已答题数、已学板块数
  -> GET /api/learn/progress 获取各板块访问次数
  -> 前端渲染环形图、进度条、完成度图
  -> 用户答题或学习后数据实时更新
