一、项目简介
================================================================================

本系统是"柴油机润滑系统教学辅助系统"，采用前后端分离架构：
  - 前端：Vue 3 + Vite（用户界面）
  - 后端：Node.js + Express + SQLite（API服务和数据库）

系统功能：
  - 用户登录（账号：LH666，密码：123456）
  - 柴油机润滑系统基本介绍（含教学视频）
  - 四大学习板块（主要作用和润滑方式、组成、油路、润滑剂）
  - 在线知识测试（15道选择题，自动评分）
  - 学习进度追踪与数据统计图表

三、软件下载与安装（Node.js）
================================================================================

【什么是 Node.js？】
Node.js 是运行本项目的必备环境，前端和后端都需要它。
你只需要安装这一个软件即可。

【下载地址】
  官方网站：https://nodejs.org/zh-cn
  推荐下载 LTS（长期支持）版本

  直接下载链接（Windows 64位）：
  https://nodejs.org/dist/v20.19.0/node-v20.19.0-x64.msi

  如果上面的版本号已过期，请访问 https://nodejs.org/zh-cn 下载最新LTS版本。

【安装步骤】

  1. 双击下载好的 .msi 安装文件
  
  2. 点击"Next"继续
  
  3. 勾选"I accept the terms in the License Agreement"，点击"Next"
  
  4. 安装路径保持默认即可（C:\Program Files\nodejs\），点击"Next"
  
  5. 在"Custom Setup"页面，保持默认设置，点击"Next"
  
  6. 【重要】在"Tools for Native Modules"页面：
     - 不需要勾选"Automatically install the necessary tools"
     - 直接点击"Next"
  
  7. 点击"Install"开始安装
  
  8. 等待安装完成，点击"Finish"

【验证安装是否成功】

  1. 按 Win+R 键，输入 cmd，按回车，打开命令提示符
  
  2. 输入以下命令并回车：
     node -v
  
  3. 如果显示类似 v20.19.0 这样的版本号，说明安装成功
  
  4. 再输入：
     npm -v
  
  5. 如果显示类似 10.x.x 这样的版本号，说明 npm 也安装成功

【如果安装失败？】
  - 请确保以管理员身份运行安装程序
  - 安装完成后需要重新打开命令提示符窗口
  - 如果 node -v 提示"不是内部或外部命令"，请重启电脑后再试

五、后端部署启动
================================================================================

【第一步：打开命令提示符】

  方法一：按 Win+R，输入 cmd，回车
  方法二：在Windows搜索栏搜索"命令提示符"，点击打开

【第二步：进入后端目录】

  在命令提示符中输入（根据你的实际路径修改）：

  cd F:\26毕设2\柴油机系统\backend

  提示：如果项目在D盘，需要先输入 D: 回车切换盘符，再cd。

【第三步：安装后端依赖】

  输入以下命令并回车：

  npm install

  等待安装完成，看到类似 "added XX packages" 的提示即表示成功。
  这一步会自动下载后端所需的所有依赖包到 node_modules 文件夹中。

  如果网络较慢，可以先设置淘宝镜像源：
  npm config set registry https://registry.npmmirror.com

  然后再执行 npm install

【第四步：启动后端服务】

  输入以下命令并回车：

  node server.js

  看到以下提示说明后端启动成功：
  "柴油机润滑系统教学辅助系统后端已启动: http://localhost:3000"

  【注意】这个命令提示符窗口不要关闭！关闭后后端就停了。
  保持这个窗口开着，然后打开一个新的命令提示符窗口来启动前端。

六、前端部署启动
================================================================================

【第一步：打开新的命令提示符窗口】

  再按 Win+R，输入 cmd，回车（不要关闭后端的那个窗口）

【第二步：进入前端目录】

  cd F:\26毕设2\柴油机系统\frontend

【第三步：安装前端依赖】

  npm install

  等待安装完成。

【第四步：启动前端开发服务器】

  npx vite

  看到以下类似提示说明前端启动成功：
  
  VITE vX.X.X  ready in XXX ms
  
  ➜  Local:   http://localhost:5173/
  ➜  Network: use --host to expose

  如果 5173 端口被占用，会自动使用 5174 等端口，以实际显示为准。

  【注意】这个窗口也不要关闭！

八、使用IDEA/WebStorm部署启动（可选）
================================================================================

如果你安装了 IntelliJ IDEA 或 WebStorm，可以用IDE的方式启动项目。

【下载WebStorm（推荐用于前端项目）】
  官网：https://www.jetbrains.com/webstorm/download/
  学生可申请免费教育许可证：https://www.jetbrains.com/shop/eform/students

  也可以使用 IntelliJ IDEA Ultimate（功能类似）：
  官网：https://www.jetbrains.com/idea/download/

  或者使用免费的 VS Code：
  官网：https://code.visualstudio.com/Download

【步骤一：用IDEA/WebStorm打开项目】

  1. 打开 IDEA 或 WebStorm
  2. 选择 File -> Open
  3. 选择"柴油机系统"这个文件夹，点击 OK
  4. 等待IDE加载完成

【步骤二：配置并启动后端】

  1. 在IDE底部找到"Terminal"（终端）面板，点击打开
  2. 如果没有看到Terminal面板，按 Alt+F12 打开
  3. 在终端中输入：
     
     cd backend
     npm install
     node server.js

  4. 看到"后端已启动"的提示即表示成功

  也可以通过IDEA运行配置启动：
  1. 点击右上角 "Add Configuration"（添加配置）
  2. 点击 "+" -> "Node.js"
  3. 设置：
     - Name: 后端服务
     - Node interpreter: 选择你安装的node.exe路径
     - Working directory: 选择 backend 文件夹
     - JavaScript file: server.js
  4. 点击 OK，然后点击绿色三角形运行按钮

【步骤三：配置并启动前端】

  1. 在IDE中再打开一个新的Terminal终端标签页
     （点击Terminal面板左侧的 "+" 号）
  2. 输入：

     cd frontend
     npm install
     npx vite

  3. 看到 VITE ready 的提示即表示成功

  也可以通过npm脚本启动：
  1. 打开 frontend/package.json 文件
  2. 在 "scripts" 中 "dev" 旁边会出现绿色运行按钮
  3. 点击该按钮即可启动前端

【步骤四：访问系统】

  同 "七、访问系统" 中的说明，在浏览器打开对应地址即可。

九、常见问题与解决方案
================================================================================

问题1：npm install 报错 / 下载很慢
解决：设置淘宝镜像源后重试
  npm config set registry https://registry.npmmirror.com
  npm install

问题2：node server.js 报错 "EADDRINUSE: address already in use :::3000"
原因：3000端口被其他程序占用
解决：
  方法一：关闭占用3000端口的程序
  方法二：在 backend/server.js 文件中，找到 const PORT = 3000
         修改为其他端口，如 const PORT = 3001
         同时修改 frontend/vite.config.js 中的代理地址为对应端口

问题3：前端页面打开后显示空白
解决：
  1. 确认后端是否正常启动（命令提示符窗口是否显示"后端已启动"）
  2. 打开浏览器开发者工具（按F12），查看Console面板是否有报错
  3. 确认访问地址是否正确

问题4：登录后一直转圈 / 提示网络错误
解决：
  1. 确认后端服务是否正在运行
  2. 在浏览器中访问 http://localhost:3000/api/sections
     如果能看到JSON数据，说明后端正常
  3. 检查前端 vite.config.js 中的代理配置是否正确

问题5：图片 / 视频加载不出来
解决：
  确认 frontend/public/materials/ 文件夹中有以下文件：
  - img/runhua_1.png, runhua_2.png
  - img/qingjie_1.jpg, qingjie_2.jpg
  - img/lengque_1.jpg, lengque_2.jpg
  - img/fangxiu_1.jpg, fangxiu_2.jpg
  - img/mifeng_1.jpg, mifeng_2.jpg
  - img/yali_1.jpg
  - img/feijian_1.jpg
  - img/chanhun_1.jpg
  - video.mp4
  如果缺失，请从 素材/ 文件夹重新复制

问题6：node -v 提示"不是内部或外部命令"
解决：
  1. 确认 Node.js 已正确安装
  2. 重启电脑后再试
  3. 检查环境变量是否包含 Node.js 安装路径

问题7：想要重置数据库（清除所有答题记录）
解决：
  1. 停止后端服务（在后端命令窗口按 Ctrl+C）
  2. 删除 backend/data.db 文件
  3. 重新启动后端：node server.js
  数据库会自动重新创建并填充示例数据


================================================================================
十、停止与重启
================================================================================

【停止服务】
  在对应的命令提示符窗口中，按 Ctrl+C 即可停止服务。
  前端和后端都需要分别停止。

【重启服务】
  后端：cd backend 然后 node server.js
  前端：cd frontend 然后 npx vite

【注意事项】
  - 必须先启动后端，再启动前端
  - 两个服务都启动后，才能正常使用系统
  - 后端启动后会自动创建SQLite数据库文件（data.db）
  - 所有答题记录和学习记录都保存在 data.db 中
