  方式一：桌面软件版（Electron）—— 推荐
============================================================

1. 安装版：
   双击 release\柴油机润滑系统教学辅助系统 Setup 1.0.0.exe
   按提示安装后，从桌面快捷方式启动即可。

2. 免安装版：
   直接双击 release\win-unpacked\柴油机润滑系统教学辅助系统.exe
   无需安装，打开即用。

※ 首次启动时系统会自动初始化数据库和加载教学资源，
  稍等几秒钟窗口会自动显示登录界面。


============================================================
  方式二：网页版（前后端分别启动）
============================================================

【前置要求】
  需安装 Node.js（建议 v18 或以上）
  下载地址: https://nodejs.org

【步骤1 - 安装依赖】（首次使用需要执行）
  打开命令行，分别执行：

  cd 后端目录:
    cd backend
    npm install

  cd 前端目录:
    cd frontend
    npm install

【步骤2 - 启动后端】
  打开一个命令行窗口：
    cd backend
    npm start
  看到 "已启动: http://localhost:3000" 表示后端启动成功。

【步骤3 - 启动前端】
  打开另一个命令行窗口：
    cd frontend
    npm run dev
  看到 "Local: http://localhost:5173" 表示前端启动成功。

【步骤4 - 访问系统】
  打开浏览器，输入: http://localhost:5173
  使用上方账号密码登录即可。


============================================================
  重新打包桌面软件（开发者用）
============================================================

  在项目根目录执行：
    npm install            （安装Electron相关依赖）
    npm run dist           （构建前端+打包安装程序）

  打包完成后安装程序在 release\ 目录下。
